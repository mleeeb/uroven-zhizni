# Уровень жизни

Пиксельная RPG о твоей жизни для Android. Уровень героя равен твоему возрасту и растёт сам в день рождения, а каким будет год, решаешь ты: задания, мечта с планом, рекорды в упражнениях, рост достатка и лента жизни с фото.

## Как установить на телефон

1. Открой на телефоне страницу **Releases** этого репозитория и скачай `uroven-zhizni.apk`.
2. Открой скачанный файл. Android спросит, можно ли устанавливать приложения из этого источника (браузера или «Файлов»): разреши.
3. Нажми «Установить». Если Google Play Защита предупредит о неизвестном разработчике, выбери «Всё равно установить»: приложение собрано из этого кода и не публиковалось в Google Play.

Новая версия ставится поверх старой, данные сохраняются.

## Где хранятся данные

Только на телефоне, в памяти приложения. В профиле героя есть кнопка «Сохранить копию»: она сохраняет все данные с фото в один файл (например, на Google Диск). На новом телефоне нажми «Восстановить из копии».

## Как устроен проект

- `app/src/main/assets/www/index.html` — сама игра (HTML, CSS, JavaScript).
- `app/src/main/assets/www/hero32.js` — пиксели героя 32 × 44, вещей коллекции, питомцев и фонов; генерируется `tools/eskizy/export_js.py`.
- `tools/eskizy/` — код эскизов (Python + Pillow), из которого нарисован герой и вещи.
- `app/src/main/java/ru/urovenzhizni/app/` — Android-часть: экран с WebView, хранение файлов, резервная копия, напоминания.
- `.github/workflows/build.yml` — GitHub собирает APK при каждом изменении и выкладывает его в Releases.

Ключ подписи `keystore/uroven.jks` лежит в репозитории, чтобы обновления ставились поверх. Для публикации в Google Play нужно будет сделать новый закрытый ключ и хранить его в секретах GitHub.

Шрифты Press Start 2P и IBM Plex Mono распространяются по лицензии SIL Open Font License (файлы лицензий в `assets/www/fonts`).
