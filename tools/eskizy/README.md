# Эскизы героя 32 × 44

Код, которым нарисованы герой, вещи коллекции, снаряжение рангов, питомцы и фоны. Python 3 + Pillow.

Пересобрать данные приложения после правок:

    cd tools/eskizy
    python3 export_js.py ../../app/src/main/assets/www/hero32.js

- `px32.py` — база героя (пол, кожа, волосы, причёски, борода), класс `Item`.
- `outfit.py` — слоты, `compose()` (порядок слоёв как в приложении), декоратор `@item`.
- `w_*.py` — вещи коллекции; `w_basic.py` — базовая одежда v0.3 и снаряжение рангов.
- `pets*.py` — питомцы; `bg.py`, `bg2.py` — фоны; анимация фонов задаётся в `export_js.py` (словарь `FX`).
- `cat_preview.py` — быстрый просмотр вещей картинкой.
